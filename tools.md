# FM24 tools and mods

FM24 has no plugin system as such. "Plugins" in practice means two things: companion apps that read the game while it's running, and mods installed into the game folders. Only download from the official sites named here. Unofficial copies of memory-reading tools are a common way malware spreads.

## Companion tools (read your save)

| Tool | What it does | Notes for this save |
|---|---|---|
| **FMRTE 24** (installed, build 24.4.2) | Real-time editor. Shows hidden attributes (consistency, important matches, injury proneness), exact CA/PA numbers, and exports player lists | Already installed. It runs as administrator, so Claude can see it but can't click into it. Click **Load Game** yourself and Claude can read the screens. |
| **Genie Scout 24** | Free scouting tool that reads the running game. Search the whole database, see CA/PA, export lists. The 'g' edition goes to donors | [Release article](https://www.fmscout.com/a-genie-scout-24-now-available.html) says it supports FM24 24.1.1 on Steam, Epic and Game Pass. Some users report errors on later patches. |
| **Player Attribute Analysis Spreadsheet** (TheFFM) | Rates every player's suitability for each role and duty as a percentage. Fed by an FM custom view printed as a web page | [Passion4FM](https://www.passion4fm.com/player-attribute-analysis-spreadsheet/). Built for FM23, so the views may need adjusting for FM24. |
| FM Dossier | Free role-fit grades, line-up builder and squad-depth gaps | **FM26 only** ([sortitoutsi](https://sortitoutsi.net/content/77041/fm-dossier)). Doesn't support FM24. |

| Mod | Use |
|---|---|

| Increase Realism megapack | Better AI transfers, finances, injuries and spread of talent |
| Data Update (sortitoutsi) | Current squads and transfers. Not useful for a save already in 2040 |
| Real Names Licence Fix | Restores real club and competition names |
| Cut-out Player Faces / Club Logos megapacks | Cosmetic |
| Instant Result | Skip-match button |

## Built into FM24 (no install)

- **Custom squad views + Ctrl+P → Web Page**: exports any squad view to HTML. This is the safest route to a spreadsheet.
- **Squad Planner** and **Data Hub**: depth planning and analytics.

## Recommendation

For this save: use **FMRTE** (already paid for) to check hidden attributes before the summer window, especially consistency and injury proneness on transfer targets. Then export squad views with **Ctrl+P** whenever you want this repo's tables updated.
